# Factor-work census pair-validator preparation

`prepare_factor_work_validator.py` adapts the frozen factor-profile pair validator for the selected-factor work census. It does not execute the generated validator, host runner, tests, or gates. It rejects changed inputs and refuses to overwrite either output.

The generator pins the exact 1343-input fixture audit, predeclared plan, runner, existing factor metadata validator, and new census metadata validator from caller-supplied SHA-256 values. It requires the expected seed `10014`, 40-package request, and exact off/profile sequence labels `factor-work-census-01-off-10014` then `factor-work-census-02-profile-10014`. Candidate implementation and contract hashes are copied from the complete audit.

For the factor timing adapter, it accepts only the known pre-census timing scope, then replaces only `LU_FACTOR_TIMING_SCOPE` with the exact expanded scope supplied from the audited `CirSim.java`; it verifies that scope occurs exactly once in that source. The census validator is separately hash-pinned and is invoked on each cold/warm full `luRepetitionProfile`. Its negative canaries are appended without removing the existing sampler, solve, factor, profile/off, and strict-reader checks. Mode-off reports must omit `factorWorkCensus` from any repetition profile, while the existing mode-off profile-absence check remains in force.
