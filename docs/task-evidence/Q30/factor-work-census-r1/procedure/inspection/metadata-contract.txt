# Factor work-census metadata validator

This Python-only helper validates the optional `profile.factorWorkCensus` object nested in `luRepetitionProfile`. Its frozen source reference is `CirSim.java` SHA-256 `18A67830EA731145D8F765F16B37BCCB3EF13C39798F0E387F40B303B307B479`. Keep the existing repetition, whole-factor timing, preflight, solve, and strict-report validators; compose this helper with them. For mode-off reports, the adapter must require `factorWorkCensus` to be absent from any present `luRepetitionProfile`; this module validates profiled objects only.

The exact census fields are `selectionPeriodTimerSelectedCalls`, `selectionRule`, `timerSelectedFactorCalls`, `selectedFactorCalls`, `completedFactorCalls`, `failedFactorCalls`, `workIsCountNotTime`, `timeCaveat`, and `byMatrixSize`. Every dimension group has `matrixSize`, `matrixInputSamples`, `factorAttempts`, `factorCompletions`, `factorFailures`, `preflightCompletions`, `preflightZeroRowRejections`, `factorBodiesEntered`, `workspaceResetCalls`, `workspaceClearCalls`, `pivots`, `pivotSearchCandidates`, `pivotSwaps`, `lowerRowProbes`, `lowerNonzeroInputs`, `lowerNonzeroFactors`, `upperColumnProbes`, `upperNonzeroColumns`, `pivotsWithNoLowerRows`, `upperProbesWithNoLowerRows`, `upperNonzerosWithNoLowerRows`, `rankOneUpdateAttempts`, `rankOneUpdatesCompleted`, `referenceClearCalls`, and `lowerRowReferencesCleared`. Dimension keys are canonical positive decimal sizes.

The work sampler selects every eighth timer-selected `lu_factorNonlinearProfiled` call (calls 8, 16, ...), using `luFactorTimingAttempts` as its denominator. For 1,453 timer attempts, the every-eighth formula yields 181 work-count samples; this is arithmetic from that denominator, not a claim about an uncompleted qualification report. It does not count all LU factor calls. Per-size sample and outcome totals must reconcile with the top-level census and remain within the current profile's full sampled-size groups. The completed qualification profile must provide the observed selected, completed, failed, and dimension counts; this validator reconciles those values rather than hard-coding them. The synthetic fixture is not evidence for production counts.

For each successful factor of dimension n on a valid square matrix, exact counts are pivots=n, pivotSearchCandidates=n(n+1)/2, and lowerRowProbes=upperColumnProbes=n(n-1)/2. `upperColumnProbes` is incremented from the `n-k-1` loop bound immediately before scanning that pivot row; a malformed short pivot row that throws during the scan can therefore leave this counter above the number of cells actually visited. Qualification matrices are valid square matrices. Failed factors retain partial counter values, but except for the tested zero-row preflight rejection this metadata validator only constrains those values with conservative bounds; it does not establish that every partial count equals work completed before failure.

All counters must be finite, nonnegative safe integers, excluding booleans. Successful factors must account for their full pivot-search and strict-triangle loops. Workspace/reference-clear counts and sparse-update counters are checked against conservative per-dimension bounds. Unknown time or timestamp fields are rejected. Work counts describe operations; they are not elapsed time and cannot be converted into seconds or savings.

`validate(profile)` returns count-only summary data. `negative_canaries(profile)` applies corruptions to a deep copy of an already-valid profile and requires rejection. The lightweight synthetic fixture checks a complete factor sample and a zero-row preflight rejection. It is metadata only; this helper does not run Java, a browser, or Q30 acceptance gates.
