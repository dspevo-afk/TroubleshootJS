# Q30 LU repetition: current profile and query-off evidence

This bundle records one isolated seed-7 factor-repetition profile run followed by a fresh query-off seed-7 control, plus retained failure history, strict-reader canaries, source provenance, and the matrix-census draft. The profile hook was experimental and is not an accepted product change or qualification claim.

The predeclared profile run reported cold 83,571 ms, proof 63,418 ms, and routing 14,565 ms. It observed 745,131 factor calls, 729 adjacent pairs, 14 exact factor matches, and 715 differences; observed factor sizes were 71–81. `performance.now` was available and the profile reported zero errors. The 21.6 ms bracketed copy/compare measurement is only a partial overhead bound: it does not include counter/modulo/window/code-generation costs, so it is not a complete overhead estimate. The profile and control are separate fresh runs; no cache, warm reuse, or performance gain is inferred.

The query-off control reported cold 82,683 ms, proof 62,407 ms, routing 14,774 ms, and 462 work units; its 390 hypothesis work units span five hypotheses. The separate warm result records a private proof-cache hit with one hypothesis work unit. The full cache receipt passed; this does not establish numerical factorization reuse. Both run summaries report cleanup PASS; the control recorded cleanup at 0.9943919 s, browser server stopped, no surviving owned processes, and no reported host errors. Raw application reports are gzip-compressed without rewriting; their uncompressed hashes are in `inventory.json`. Run manifests and process provenance are sanitized. Browser profile/cache trees are excluded.

Strict validation used frozen validator source hash `56d11822c0456ef4372bfa7cdfc0f3d79965e6aa895fcfd665e0d4a8b72da312`. Both current-plan readers passed; each ran 43 negative canaries. Full raw report parity passed outside the two profile-only fields and declared timings. Exact request, owner, physical, proof, work, and cache checks passed. A separate sampler metadata test passed for one actual cold record plus 12 mutations, including adjacency, census, clock, signed zero, size, overhead, and query-off-presence checks. A07 and disabled-generation canaries passed; the maintained A07 strict reader passed its three negative cases. These checks validate the evidence parser/metadata contract, not product qualification.

Historical experimental attempts are retained without discarding failures: native r1 and r2 failed at 35.319 s and 35.113 s; native r3 and r4 passed at 45.586 s and 46.887 s. Native clock timing for the profile was unavailable. The matrix census ran one real step for each of three seeds and records logical support dimensions plus exploratory cloned-matrix dimensions. These are not actual installed-profile dimensions and are not qualification evidence; no block solver was implemented. The exploratory census suggests that per-factor structure discovery and copying could consume the pivot-scan savings predicted for a block solve; this is not a measured speed result.
