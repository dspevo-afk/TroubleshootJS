## Selected next optimization

Factorization still accounts for **61.5%** of measured sampled-kernel time
(0.7915 of 1.2875 sampled seconds). Sampling one of every 64 accepted steps
covers 11,609 factorizations. A separate structural sample of 726 completed
factors finds 11.9% nonzero lower entries; weighted by nonzero upper
coefficients, **82.55%** of current row probes encounter a zero factor.
These measurements support testing exact sparse row indexing in the existing
Crout loop before working on the approximately 20-second router cost.

The proposed integer masks are scratch rebuilt on each factorization, with
pivot-aware row membership. They do not cache numerical LU results or graphs.
Arithmetic order, finite checks, pivot choices, settling, hypotheses, service,
retest, physical admission and the frozen budgets must remain unchanged.
The subsequent [packed-index experiment](../sparse-index/README.md) was slower
and was removed from production source. Its phase profile now motivates a
per-row list experiment; no further optimization is accepted yet. Q30 remains disabled.
