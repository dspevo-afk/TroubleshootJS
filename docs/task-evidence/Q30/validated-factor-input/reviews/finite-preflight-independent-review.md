# Independent review: finite-preflight fast path

**Disposition:** no correctness blocker for the narrowly scoped fast path described. This is a source-invariant proof, not approval to weaken general LU input validation.

- At analysis, simplifyMatrix copies the finalized matrix into origMatrix (CirSim.java:2943–2965); stampCircuit then runs requireFiniteMatrix() before returning for nonlinear circuits (2843). A failed scan is caught by analyzeCircuitOwned, which calls stop; stop nulls circuitMatrix (2802–2805, 3102–3108), so no trial factors that failed baseline.
- Every nonlinear trial restores each matrix cell from that validated origMatrix, calls the ordered doStep elements, then factors (3329–3364, 3381–3391). The only source writes to matrix cells found are that restore/copy and stampMatrix accumulation. stampMatrix checks the incoming stamp and the accumulated result (3188–3208, 3211–3215). An exception after an overflowing accumulation aborts the owned operation; it cannot reach factorization in that trial. A later trial restores the validated baseline first.
- Reentry does not create an intervening writer: solver operations require an idle boundary, and the A07 real-model reentry fixture checks that recursive runCircuit/analyzeCircuit calls are rejected (CircuitSolverExecutor.java:36–44, 98–110; A07SolverDeveloperVerifier.java:73–90). No source doStep or startIteration writes directly to circuitMatrix/origMatrix.
- Task 41 snapshots capture matrix references plus value copies only at an idle solver boundary (Task41SimulationSnapshot.java:190–240; CircuitSolverExecutor.java:252–255). Private proof opens from that captured owner, installs a detached graph, explicitly analyzes it, and restores the saved matrix/state on close (PrivateSolverContext.java:16–48, 77–125; snapshot restore at 587–606, 712–728). Failed cleanup quarantines the exact original owner. Snapshot restoration therefore does not feed a stale proof matrix into the next factor trial.
- Existing A07 cases exercise nonfinite/overflowing nonlinear stamps through an actual private trial and require numerical failure plus owner restoration (A07SolverDeveloperVerifier.java:28–45, 94–106, 461–468). LuFactorizationChecks independently compares Crout factors/pivots/solutions and verifies NaN/±Infinity rejection through both existing 3- and 4-argument general LU overloads and overflow rejection (LuFactorizationChecks.java:63–104, 156–185).

**Required boundary if implemented:** use a separate non-public factor entry called only after the nonlinear trial restore and checked doStep sequence. Keep the all-zero-row scan, pivot and elimination order, and every arithmetic-result finite guard. Leave both existing general LU overloads fully validating; keep RHS/full-row and publication checks. Do not route arbitrary matrices, linear analysis, inversion, or test-supplied matrices through the trusted entry. A future direct matrix writer, mutable alias, or callback that bypasses stampMatrix would invalidate this proof.

No source was edited and no tests/builds were run.
