# Seed-10014 host-polling source analysis

This is a read-only source/report trace; it does not change source, runner timeouts, or acceptance budgets and does not rerun the browser.

The 40-package application report records `constructionMs=31788` and `warmConstructionMs=32647`. In the D01 verifier, `Runner.advance()` is scheduled through a GWT `Timer`, but its `construct()` and `constructWarm()` callbacks each call `Rb30Generator.constructNormalForQualification(seed)` inline. That method creates a `SeededPcbLayoutGenerator.Session` and drains it with `while (!routing.advance()) { }` before returning. The two route/build calls therefore do not yield between session advances. Their 31.788-second and 32.647-second phase durations each span about three 10-second Playwright attribute-read timeouts, matching the six `locator("html")` waits recorded in the host runner.

The report's cold-proof maximum individual work unit is 1.814 seconds; the longest named service-preparation canary is 4.092 seconds. The failed-cleanup canary reports 19.954 seconds total without a per-unit maximum, so the report cannot exclude every other contributing stall. The host runner stores no timestamps for individual attribute-read errors. The synchronous route construction is therefore a strong phase-level explanation, not a proven one-to-one attribution for all six waits.

The maintained browser runner collects `attributeReadErrors`, but its `browser_error` outcome predicate currently checks only page, HTTP, console, and listener-cleanup errors. This permits the aggregate runner outcome to say PASS while six state-attribute reads timed out. The preserved host receipt remains failed/limited for polling purposes.

This D01 path is the explicit debug-only `tsjQ30D01` branch. It invokes the private diagnostic verifier and records `normalAdmission=false` and `playerPublished=false`. The normal acceptance branch is separately selected by `tsjQ30NormalAcceptance`; `Q30NormalAcceptanceVerifier.start` asserts the unchanged 90,000-ms job, 5,000-ms unit, and 640-step coordinator limits. The D01 construction times are not a measurement or failure of that normal coordinator contract.
