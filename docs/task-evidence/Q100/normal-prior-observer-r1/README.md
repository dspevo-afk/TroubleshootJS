observe_caller_facts takes an explicitly authenticated current reader module,
tool_specs, source_specs, directory_specs and absence_specs. It returns actual
byte facts, exact shallow directory closures, rechecked absence facts and their
observation evidence. It imports no reader or default path and discovers no
file path from a manifest. Reader source/provenance and configuration authority
belong to the caller. Callability or a supplied hash string is not that proof.

Directory observation compares sorted names with exact seven-name call or
two-name native-data closure, inspects every immediate child as a regular file,
rejects reparse/escape and rechecks child/directory/root identities. It never
recursively scans resources. Absence requires actual ENOENT/WinError2 or3,
strict containment, canonical existing ancestors and repeated missing-component,
target, nearest-ancestor and root checks. Existing/access/unexpected errors do
not become absence. Source byte and resource observations are rechecked finite
observations, not an atomic host snapshot. The caller must recheck before final
acceptance and keep current SOURCE/runtime identity outside canonical context.
