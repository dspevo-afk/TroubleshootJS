# Component acceptance within the Z sequence

This milestone completes the current context codec/Java DATA emitter and the
standalone pure N/P07 kernel extraction. It is a necessary component substep of
PLAN_R1, not completion of its later normalizer/host/native integration sequence.
The normalizer is IN PROGRESS in a separate private source assignment and is not
published or accepted here. No required normalizer gate is silently omitted.

Accepted evidence is structural/static context validation, deterministic emitted
DATA, source-preserving extraction and synthetic runtime fixtures. The codec does
not authenticate prior records or recompute their physical/hash qualification;
the normalizer and source-bound caller retain that responsibility. Synthetic
246-PAD structures and tiny P07 fixtures are not playable100 or functional boards.

Generated API is fixed before execution: schemaTag/contextSha256 return String,
dataEntries returns int and dataJson returns a fresh Map<String,Object>. Only
nativeProjection is emitted. Current runtime identity stays external. Entry count
is container/copy inventory, not all factory work. The actual factory/preflight
operations still require setup admission before capture; no native budget proof
is inferred from the synthetic canary or static operation worksheet.

Actual20-role normal-prior ingestion remains unstarted. Parent source/reader/
normalizer gates and a separate explicit phase record precede it. Full N-run
positive, original/PAD/group/export reconciliation, current host/native source/
class/tool/argv/capture admission and the one genuine original+NULL/OBSERVE remain
later gates. No extra original/control/arm/retry is granted. All caps, exact seeds,
independent oracles, excluded full30 and protected-data restrictions remain.
