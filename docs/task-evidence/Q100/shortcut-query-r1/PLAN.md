## Pre-gate ownership and accounting clarification

Source review identified a limitation of every bounded incremental snapshot:
a caller mutation to a not-yet-copied cell can be absorbed into its initial
snapshot. This helper requires exclusive, synchronous caller ownership of the
live Router, layout and endpoint state from begin through completion. It is not
a detector of arbitrary concurrent or reentrant mutation during the initial copy.
The actual adapter satisfies this precondition: each pending value unit checks
the same route/Search/Branch/Publisher/face/path/goal identities, advances only the
diagnostic cursor, checks the frozen stage1/index66 again, and returns without
P07 work. No thread, executor or asynchronous mutation path is involved.

All before-query and after-query comparison assertions remain required. The
existing source-mutation canary changes an already-copied cell and proves that
case only; it does not establish an atomic full-state snapshot. No production
version guard, uncharged atomic scan, extra allowance or broader mutation claim
is introduced. A caller requiring concurrent snapshot isolation needs a separate
source mutation protocol; that is outside this exclusively owned diagnostic.

The cursor now charges the full allowance passed to each copy/comparison task,
including early completion and zero-entry structural work. workSteps and lastWork
are conservative budget debits, not exact inner-entry counts. copyEntries and
comparisonEntries retain the actual task counters. activeMillis accumulates
nanoseconds across advances plus final payload assembly, then converts once;
the final constant-time Result wrapper and later JSON serialization are excluded.
The operation/value-unit clocks still include all that work. No published timing
or routing limit changes.
