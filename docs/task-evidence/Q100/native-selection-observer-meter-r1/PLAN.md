# Live versus stale release accounting

headReleases counts borrowed-head release attempts in a live observer callback
only, including live rejection/failure paths. It does not include stale calls.
This follows the existing snapshot releases counter and preserves sealed state.

A stale callback charges rejection plus each nonnull borrowed argument's release
to the supplied separate rejection Meter (three units for snapshot+head), then
rejects. It changes no original observer counter, selection or original Meter.
There is no new observer-owned cumulative stale counter. This clarifies the
existing frozen no-state-mutation rule and does not change a budget or owner.
