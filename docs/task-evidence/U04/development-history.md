# U04 session, resources, settings and real inventory

Status: implementation complete; combined qualification IN PROGRESS.
See [the integrated candidate and gates](../REL-A/README.md).

The typed Java session owns menu, preparation, ticket, workbench, retest, results
and error transitions. Revocable tokens guard old session callbacks; modal leases
guard closed or superseded Shop controls. Cancellation retains the previous
admitted owner, while unsupported exact replay rejects without substitution.
Current replay transports every signed-long digit and reports interpretation
epoch and the compiled build identity.

The product bridge exposes public complaint, names, catalog entries and actual
loose counts. It never returns private fault, original-part specification,
diagnostic proof or solver data. Normal tray labels use neutral runtime inventory
ordinals and permitted physical markings. Shop acquisition calls current package
adapters to create a real loose part with live CircuitJS backing; installed parts
and bindings remain unchanged. Removal and tray installation are separate actions.
The normal sidebar no longer duplicates the old direct-install catalog surface.

Resources provide generic instrument/isolation/repair guidance and resistor
marking reference. Persistent contrast, text-size and reduced-motion preferences
affect presentation only. Invalid/unavailable browser storage produces a clear
session-only recovery state. Unsupported features are explicitly unavailable.
