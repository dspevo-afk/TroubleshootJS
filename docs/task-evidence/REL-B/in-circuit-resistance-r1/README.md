## Why the regulator change was necessary

The first production pass measured5.194kOhm, then probe reversal threw at -32mV
on E02's disabled output and locked cleanup. Fixed8x50us native samples had missed
it. The new healthy resolved-1004 physical fixture uses longer actual CircuitJS
advancement with adaptive0.4ms maximum steps; it reproduced the same failure after
a successful same-post intermediate read. It does not apply the browser's fault,
and is not claimed to recreate that exact faulty state.

E02 already stamps a symmetric passive1M output-to-RETURN leakage law when its
target is zero. Validation now admits either polarity within the declared absolute
voltage envelope. Independent1V/1k load-line and power checks prove that branch
absorbs the injected energy and draws none from INPUT; removing the actual source
restores zero output. Active negative outputs and excessive terminal voltages
remain rejected. This is an explicit bounded static approximation, not a real
device reverse-rating or protection-diode claim. Interpretation epoch18 separates
this meaning; serialized dump format6 is unchanged.

Native after-fix healthy replay: forward9065.38Ohm, intermediate0Ohm,
reverse7039.41Ohm, cleanup true/boardOFF. Nonlinear asymmetry is permitted;
those values are observations rather than fixed fixture goldens. In the actual
faulted production browser, redRREF_L.1/blackRREF_L.2 reads5.194kOhm; moving red
to.2 reads0Ohm; moving black to.1 reads5.194kOhm without exception or cleanup lock.
The part stays installed and tray0. CONT and DIODE show the full ISOLATE COMPONENT
message at14px; Ω reentry restores24px numeric type, with50px content/scroll height.

The meter retains its existing finite sampling interval; this is not an arbitrary
stored-energy network DC-equilibrium guarantee. Real meter excitation may require
natural decay before subsequent physical service. Cleanup never clears stores.
