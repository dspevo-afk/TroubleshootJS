## Bounded routing lookup

The current optimization adds a per-column immutable index over the existing
courtyard candidates used by `PcbNetRouter`. Candidate encounter order and the
existing exact geometric predicates remain authoritative. The index narrows
only the candidates inspected by each eligible column query; the non-adjacent
path retains its full-scan fallback. The route search, path selection, edge and
via rules, costs, ordering, and resulting geometry must remain byte-for-byte
equivalent under the independent geometry and routing oracles.

The earlier r2 runtime scope remains in effect: `TopologyPlacementGraph`
freezes its completed per-component link lists once and returns read-only views;
`PcbFootprint` caches one defensive copy of its fixed placement envelope while
the planner still applies its access and label margins. Link order, courtyard
union, padding and all existing placement constraints remain unchanged.

Session restore continues to use bounded work units: at most four consecutive
history actions per history unit, followed by source units and the existing five
fixed isolate/restart/damage/validation actions. The declaration remains
`ceil(history / 4) + sources + 5`, plus one atomic publication unit. Every
history action retains its owner checks, order, replay, solver settlement and
checkpoints. The new minimum/maximum proof admission reserves the mandatory
minimum plus the same publication tail before proof; it preserves the full
declared maximum and refuses an extra proof unit before consuming reserved tail
work. Candidate retries recompute their own reservation.

The restore permit still binds the exact job, request, candidate, controller,
graph, installation and saved value. It checks private restore continuity and
retains the exact pristine diagnostic-proof receipt through every yield and
through publication qualification. A replacement receipt is stale even when
owner and context are otherwise unchanged. This does not change the proof
program or admit an incompletely proved candidate.
