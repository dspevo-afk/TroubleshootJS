# Pocket decision diagnostic worker handoff

This bounded change is limited to `PcbPlacementPlanner.java` observer instrumentation and the native-only `PcbPocketDecisionDiagnosticContractTest.java`. No Java, GWT, native contract, or player-flow command was run by this worker. The root owns the maintained compile/runtime gates, input freeze, evidence archive, registry, and production restoration.

The planner observer is package-scoped and optional. `planMedium` installs a local capture only when an observer matches the planner seed, candidate attempt, and density 14. `mediumPlace` reports existing ring-search and whole-outline-fallback evaluations after their existing fit and score work, then reports the chosen placement. `planMedium` snapshots the validated raw plan immediately before the placement compactor and the returned plan after compaction. Snapshot footprints and outlines are copied; region entries are immutable. An absent observer adds no origin probes, fits, score calls, or budget charges. The test installs the observer only around the ordinary synchronous `Session` route and restores the previous observer in `finally`, including session creation failures.

The two accepted root seeds remain `-1022` with selected attempt 0 and `42` with selected attempt 1. The observer matches the actual planner seed, which is the accepted `layoutSeed`; output includes both top-level `seed` and diagnostic `traceSeed`, plus diagnostic `selectedAttempt` and `density`. Top-level `PCB_POCKET_DECISION_CASE` JSON retains the accepted source, graph, layout, selected-attempt, rank, statistics, and geometry receipt keys. The terminal marker is `PASS: PCB pocket decision diagnostic contracts ... measurementOnly=true causalClaim=NONE`.

The nested `diagnostic` object exports `status`, `bindingStatus`, `reasons[]`, trace `{records,cap,capped,chosenPlacements}`, raw/returned/selected plan fingerprints, selected-plan match booleans, and `chosenComparisons[]` for every raw-plan component. Each comparison carries raw and actual recorded coordinates, rotation, mounting side, chosen score, and explicit coordinate/pose/comparability flags. The raw rectangle object carries grid 10, occupancy kind, actual allocated `cells`/`rasterCells`, requested full-outline `rasterCellCount`, `emptyRectangleCells`, fixed raw-envelope domain bounds/count, `domainPolicy=FIXED_RAW_ENVELOPE_BOUNDS_CLIPPED`, rectangle bounds/area, and any reason. The sample object reports limits, whole-plan validations, rectangle recomputations, `capped` and `capReasons[]`, then up to four nearest components with actual raw-versus-recorded chosen facts and `sampledOrigins` plus the corresponding `origins[]` rows.

Each origin row preserves sequence, origin, pose, fit, logged effective score, validation status, whether the envelope leaves the fixed measurement domain, optional rejection reason, and post-move rectangle/score comparison facts. `rectangleRecomputations` counts completed post-move rectangle scans after successful full validation; baseline rasterization is excluded. The 16-scan cap is checked before another full validation, so every `fullValidation=PASS` row has a post-move area and contributes exactly one recomputation. At most 128 calls to the existing full-plan validator are made per root. A trace, raster, origin-sample, validator, or rectangle-scan cap yields `INCONCLUSIVE` with a reason. A `WITNESS` status is emitted only when the returned plan fingerprints the actual selected `PlacementCandidate.plan`, all raw-plan choices match their actual recorded coordinates and pose, there are no caps, and a logged same-pose origin passes full validation, strictly lowers the raw access-envelope rectangle, and has a strictly worse logged effective score.

The rectangle is measured only on the selected raw pre-compaction plan. Its domain is the grid-rounded bounding box of the union of full access envelopes from that raw plan and remains fixed for every trial; envelopes outside that domain are clipped for this one metric, while the existing full-plan validator still checks the complete placement. This is not routed protected whitespace, final outline area, a routability claim, or an all-seed claim. Absence of a witness is reported as inconclusive for the declared finite sample.
