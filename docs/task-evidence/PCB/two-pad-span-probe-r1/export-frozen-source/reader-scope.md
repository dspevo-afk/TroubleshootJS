# Two-pad span probe reader scope

`qualify.py` reads the sealed one-seed control and private-variant evidence for
`tsj-alpha/6/MEDIUM/COMPOSED_CONTROLLED_INDICATOR/-2750102463469069236`. It
reuses the pinned composed-rejection reader with only its already-reviewed
identity and packing-epoch adaptations. Each row still passes the original
normal-admission, geometry, routing, quality, access, graph-immutability,
independent metric, endpoint, and whitespace-sampler checks and retains the
327-assertion native marker.

The reader checks actual host canary exit and cleanup records separately from
recorded process-birth exits. It verifies the frozen eight-file private input
seal, source-only review, and unchanged six-field execution provenance. The
control row, sampler, and two typed cause observations must match the accepted
receipt except for the existing packing clock. The variant must preserve the
accepted logical graph, components, pads, nets, and endpoints.

Four `packing-span-checkpoint@1` rows are required in `SOURCE`, `ORDINARY`,
`PAIRED`, `FINAL` order. The reader independently rebuilds the complete
exactly-two-pad net inventory from the exported logical nets, checks endpoint
IDs and span arithmetic, verifies canonical-plan SHA-256 values and signed-long
seed transport, and checks shared cumulative evaluation bounds. It compares
source spans with the accepted selected pad endpoints, independent of any
whole-board crop translation, and requires both arms to report identical
source checkpoints. The variant ordinary stage and final
selected physical pads may not exceed those source spans. A paired-stage span
increase requires a final source-geometry fallback that retains the paired
evaluation count; otherwise the final checkpoint must equal the paired
checkpoint apart from its phase label.

The final decision is `GO` only when the actual selected variant has strictly
smaller area and copper, vias, and protected-void metrics satisfy the existing
strict selector's nonworse bounds. An unchanged accepted incumbent is `NO_GO`.
This result is finite to the single replay and does not authorize production
promotion. The span observer and filter remain private experiment artifacts;
they do not prove routing success, electrical behavior, manufacturing
fitness, optimality, or behavior on other seeds.

The reader's negative controls target the inherited identity, endpoint,
independent-metric, and epoch assertions; the accepted-row packing-counter
boundary; missing two-pad inventory; bad span arithmetic; hash-valid stage
correlation changes; final evaluation-count changes; and source-fallback count
preservation. This file and the reader are source-only until root runs the
sealed host canaries and native control/variant phases.
